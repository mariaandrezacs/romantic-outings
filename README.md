# Programas Pra Namo

10 programinhas românticos em HTML, CSS e JavaScript. Só abrir no navegador e clicar. Não precisa instalar nada.

## Como mandar pelo WhatsApp

1. Selecione a pasta `html`.
2. Clique com o botão direito → **Enviar para → Pasta compactada (zipada)**.
3. Envie o arquivo `.zip` pelo WhatsApp.
4. Ela baixa, descompacta e abre o arquivo `index.html`.

> Se o WhatsApp bloquear `.zip`, mude a extensão para `.txt` e peça pra ela renomear de volta pra `.zip` antes de extrair.

## Como executar

1. Extraia o `.zip`.
2. Entre na pasta `html`.
3. Clique duas vezes em `index.html`.
4. Vai abrir no navegador normal (Chrome, Edge, etc.).

## Projetos

1. **Contador de Namoro** - coloca a data que começaram
2. **Motivos que Amo Você** - gera 10 motivos aleatórios
3. **Sorteador de Date** - sorteia o próximo encontro
4. **Cartinha Digital** - cartinha fofa pra abrir
5. **Alfabeto do Amor** - cada letra tem um significado
6. **Pomodoro Juntos** - timer pra focar junto
7. **Jogo da Forca** - forca com tema casal
8. **Cápsula do Tempo** - salva mensagem em arquivo
9. **Surpresa do Dia** - revela uma surpresa aleatória
10. **Quiz do Casal** - quiz "quem é mais"

## Dica

Edite as frases, datas e nomes nos arquivos `.html` antes de enviar. Basta abrir no Bloco de Notas e trocar o texto.
